🦗 Young Grasshopper — Install Guide

Copy-paste these commands into the client's terminal. One step at a time.

⚠️ You'll need the client's sudo/admin password for steps marked with 🔑
🐧 Linux / Ubuntu
🍎 Mac
🪟 Windows

Prerequisites

🔑 STEP 1 — Install System Packages
Runs once. Gets Python and dependencies ready.
sudo apt update && sudo apt install python3-pip python3-dotenv python3-croniter curl -y
STEP 2 — Install Hermes Agent
One-line install from Nous Research.
curl -fsSL https://hermes-agent.nousresearch.com/install | sh
STEP 3 — Verify Hermes Works
Check that Hermes is installed and ready.
export PATH=$PATH:$HOME/hermes-agent && hermes --version
✅ Should show: Hermes Agent v0.17.0

Young Grasshopper Portal

STEP 4 — Set Up Portal
Creates virtual environment and installs dependencies.
mkdir -p ~/younggrasshopper-portal/templates && python3 -m venv ~/younggrasshopper-portal/venv && source ~/younggrasshopper-portal/venv/bin/activate && pip install flask flask-session twilio python-dotenv -q
STEP 5 — Set Up Health Check Cron Job
Daily check runs at 9am. Reports machine health.
export PATH=$PATH:$HOME/hermes-agent && hermes cron create '0 9 * * *' 'Check machine health: uptime, disk, memory, portal status.' --name 'Daily Health Check' --deliver origin
STEP 6 — Install Tailscale (for remote access)
Enables me to SSH in and help remotely.
curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up
After this, share the Tailscale invite link with Ryan.

Prerequisites

🔑 STEP 1 — Install Homebrew (if not installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
STEP 2 — Install Python + Dependencies
brew install python && pip3 install flask flask-session twilio python-dotenv
STEP 3 — Install Hermes Agent
curl -fsSL https://hermes-agent.nousresearch.com/install | sh
STEP 4 — Install Tailscale
brew install --cask tailscale
Open Tailscale from Applications and sign in.
⚠️ Windows 10+ required. Windows 8.1 is NOT supported — install Ubuntu instead.
